# 90 Day Reset

A habit tracker for your phone. Tick off five habits every day for 90 days, then claim your reward.

- 🌙 Early to bed
- 🌅 Early to rise
- 🥗 Eat clean
- 👟 12,000 steps
- 🏋️ Gym

## Features
- **Today screen:** one-tap checkboxes, a steps counter with +1k/+2k/+5k buttons, optional weight and notes.
- **Go back to past days** with ‹ › to fill in a day you missed logging.
- **Progress screen:** reward countdown, current and best streak of perfect days, a 90-day colour map, a success rate for each habit, and a weight trend chart.
- **Works offline** once installed. All data stays on your phone in browser storage, with no account and no server.
- **Backup:** export or import a JSON file from Settings.

## Put it on your phone
1. Host it with GitHub Pages: repo **Settings → Pages → Deploy from branch → `main` / root**.
   It will be served at `https://<your-username>.github.io/buildingwithsciencelikeapp/`.
2. Open that link on your phone:
   - **iPhone (Safari):** Share → *Add to Home Screen*
   - **Android (Chrome):** ⋮ → *Install app* / *Add to Home screen*
3. Open it from the home-screen icon. It runs full-screen like a normal app.

> Your progress is saved in the browser on that phone only. Use **Settings → Export** now and then to keep a backup.
